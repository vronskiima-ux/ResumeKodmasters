**Краткое описание проекта**

Одностраничный адаптивный сайт-резюме, созданный с использованием HTML, CSS и JavaScript без применения сторонних фреймворков. Проект демонстрирует уверенное владение базовыми веб-технологиями:

    -Семантическая вёрстка и использование Flexbox / CSS Grid.
    
    -Работа с CSS-переменными для создания системы тем.
    
    -Работа с DOM через JavaScript для реализации логики фильтрации и поиска элементов без перезагрузки страницы.
    
    -Работа с localStorage для сохранения пользовательских предпочтений.

**Ссылка на опубликованный сайт:** https://vronskiima-ux.github.io/ResumeKodmasters/

**Выполненные требования:**

    -Создано адаптивное одностраничное резюме, содержащее актуальные сведения о разработчике.
    
    -Страница имеет логичную структуру с использованием HTML-тегов header, main, section, nav, footer.
    
    -Дизайн корректно отображается на десктопе, планшете и мобильном устройстве.
    
    -Раздел Навыки является интерактивным.
    
    -Реализована фильтрация навыков по категориям (Frontend, Backend, Tools, Other).
    
    -Реализован  нечувствительный к регистру поиск по навыкам.
    
    -Поиск и фильтр работают одновременно без перезагрузки страницы.
    
    -При отсутствии подходящих элементов выводится сообщение "Ничего не найдено".
    
    -Добавлена возможность переключения между светлой и тёмной темой.
    
    -Выбранная тема сохраняется в браузере после обновления страницы.
    
    -Проект выполнен без использования запрещенных фреймворков.
    
    -В качестве дополнительного функционала реализована плавная каскадная анимация появления карточек с навыками при фильтрации.

**Невыполненные требования:**

Невыполненных требований нет, все обязательные пункты технического задания реализованы в полном объеме
