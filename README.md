# Интерактивное резюме

## Описание
Одностраничный сайт-резюме, созданный в рамках вступительного задания. 
Реализована адаптивная верстка, переключение светлой/темной темы с сохранением в localStorage, а также поиск и фильтрация навыков по категориям без перезагрузки страницы.

## Ссылки
- **Опубликованный сайт:** https://vronskiima-ux.github.io/resume/

## Выполненные требования
- Адаптивное одностраничное резюме
- Интерактивный раздел навыков (поиск и категории работают совместно)
- Светлая и тёмная тема с сохранением выбора
- Публичный репозиторий на GitHub и публикация через GitHub Pages
- Отсутствие сторонних CSS/JS фреймворков

## Референсы
Дизайн создавался самостоятельно с упором на минимализм и читаемость, без использования сторонних шаблонов.
